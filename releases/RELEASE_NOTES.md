## ⚡ What's New in v1.0.0

### 1. Windows Desktop Command Center
- **Adaptive Multi-Pane Interface**: High-density desktop workspace designed for estimators, managers, and accountants.
- **Collapsible Glassmorphic Sidebar**: 1-click access to *Dashboard*, *Leads Pipeline*, *Customers*, *Payments*, *Work Teams*, *KEDL Net Metering*, *Stock Inventory*, and *Support Tickets*.
- **Omni-Search `<Ctrl + K>`**: Search across hundreds of leads, invoices, component serial numbers, and DISCOM files in under 50ms.
- **Milestone Financial Approvals**: 4-stage automated milestone schedules (Advance, Structure, Material, Grid Commissioning) with instant ledger verification.

### 2. Android Mobile & Field Companion
- **Rooftop Inspection & Site Surveys**: Geo-tagged camera photo uploads for shadow analysis, earthing resistance, and inverter mounting.
- **Offline-First Resilience**: Automatic local caching for work on remote sites with zero cellular coverage.
- **Client Transparency Portal**: Real-time solar energy generation telemetry (kWh, CO₂ offset, rupee savings), warranty vault, and DISCOM net-meter tracking.

### 3. High-Performance Render Cloud Backend
- Fully integrated with the live Render cloud infrastructure (`https://solar-mobile-app.onrender.com/api/v1`).
- 104 asynchronous REST endpoints powered by FastAPI, SQLAlchemy, and PostgreSQL.
- Sub-100ms response times and bank-grade TLS 1.3 encryption.

## 🚀 Installation Instructions

### Windows (64-bit)
1. Download **`SolarPro-Windows-x64-v1.0.0.zip`**.
2. Right-click and choose **Extract All...** to your preferred folder (e.g. `C:\SolarPro` or Desktop).
3. Double-click **`solar_pro.exe`** to launch immediately.

### Android
1. Download **`SolarPro-Android-v1.0.0.apk`** to your phone or tablet.
2. Tap the downloaded file in your browser / file manager.
3. If prompted, toggle **"Allow installation from this source"**.
4. Tap **Install** and open SolarPro!
